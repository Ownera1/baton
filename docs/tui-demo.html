这版改了什么

  • 结论放在最上面：详情顶部的摘要块集中显示状态、耗时、检查和改动；失败时直接写出哪条检查、哪一行、期望和实际值。
  • 列表按要不要处理分组：需要关注、进行中、已完成。状态同时用符号和颜色表示，色弱也能分辨。
  • 任务用对话标题命名：主 Agent 派活时传标题，缺省取任务首行；ID 移到详情里。
  • 详情按对话展示：每一轮的提问和回复上下排列，回复按 Markdown 渲染，工具调用默认折叠成一行。
  • 比例可调：[ ] 每次 5%，= 复位，z 只看详情，也可以拖动分隔线；比例会记住。
  • 实时事件更好读：每个工具调用一行，读文件、改文件、跑命令用不同符号，命令带退出码和耗时。
  • 设置在同一个面板里：按 s，左栏换成 ~/.config/baton/config.json 的 24 项（全局 agent、timeout、max_parallel，面板 theme，每个 Agent 的 model、effort、path、hidden），右栏说明当前项：可选值、这个 Agent 的完整命令预览（配置带来的参数高亮）和保存后的文件（改动行标绿）。←→ 切换取值，enter 输入，d 恢复默认，u 撤销，ctrl+s 保存，esc 回到对话。切换 theme 时整个面板立即换色，默认跟随终端（这里即上方的浅色/深色按钮）。比例、分隔线和主题与对话模式共用，任务计数照常刷新；未保存的改动在顶栏提示，退出前要确认。baton config 在终端里直接以这个模式打开。
  • 浅色和深色两套主题：默认跟随终端背景自动选择，也可以用 --theme light 或 --theme dark 固定。两套主题的状态色都单独调过，浅色背景上的黄色和青色更深，保证可读。
